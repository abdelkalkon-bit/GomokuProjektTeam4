# TC-18 – Bevara matchens state
## Relaterat UC:
UC-09 / UC-12
## Förutsättningar:
En match är igång och flera drag har gjorts.
# Steg:
1. Starta en match.
2. Gör flera drag.
3. Pausa eller lämna matchen enligt systemets funktion.
4. Återuppta matchen.
# Förväntat resultat:
* De tidigare placerade stenarna finns kvar.
* Rätt spelare har tur.
* Matchen fortsätter från samma state.
