# TC-23–Visuell stabilitet
## Relaterat NFR:
NFR-09
## Förutsättningar:
En match är igång.
# Steg:
1. Starta en match.
2. Placera flera stenar på olika platser.
3. Kontrollera spelplanens storlek och placering.
# Förväntat resultat:
* Spelplanen ändrar inte storlek.
* Spelplanen flyttar inte på sig.
* Rutorna behåller samma storlek.
