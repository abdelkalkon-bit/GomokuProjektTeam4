# TC-20 – Samma state hos båda online-spelarna
## Relaterat UC:
UC-12
## Förutsättningar:
Två spelare är anslutna till samma online-match.
# Steg:
1. Starta en online-match.
2. Spelare 1 gör ett drag.
3. Kontrollera spelare 2:s spelplan.
4. Gör samma kontroll efter flera drag.
# Förväntat resultat:
* Båda spelarna ser samma stenar.
* Båda spelarna har samma aktuella spelstatus.
* Turordningen är samma för båda spelarna.
