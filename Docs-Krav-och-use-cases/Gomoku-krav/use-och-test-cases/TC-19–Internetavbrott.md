# TC-19 – Internetavbrott
## Relaterat UC:
UC-11
## Förutsättningar:
En online-match är igång.
# Steg:
1. Starta en online-match.
2. Gör några drag.
3. Stäng av internet en kort stund.
4. Anslut till internet igen.
# Förväntat resultat:
* Matchen försvinner inte vid ett tillfälligt internetavbrott.
* Den senaste spelstatusen finns kvar.
* Rätt spelare har tur efter återanslutningen.
