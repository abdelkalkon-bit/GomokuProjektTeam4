# TC-14 – Skapa och kopiera spellänk
## Relaterat UC:
UC-06
## Förutsättningar:
Användaren kan skapa en online-match.
# Steg:
1. Skapa en online-match.
2. Kontrollera att en invite-länk visas.
3. Välj "Kopiera länk".
# Förväntat resultat:
* Matchen får ett match-ID.
* En spellänk visas.
* Länken går att kopiera.
