
# TC-24–Ingen personlig information i spellänk
## Relaterat NFR:
NFR-08, NFR-10
## Förutsättningar:
Användaren kan skapa en online-match.
# Steg:
1. Skapa en online-match.
2. Kontrollera spellänken som skapas.
# Förväntat resultat:
* Spellänken innehåller ingen personlig information om spelaren.
* Det behövs inga personuppgifter för att spela.
