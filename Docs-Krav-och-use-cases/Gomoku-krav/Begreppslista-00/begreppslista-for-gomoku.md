# Begreppslista

Denna begreppslista visar alla domän och tekniska termer som används i kravspecifikationen. 

| De olika termerna | Definitionen av dem |
|---|---|
| Spelare | En person som spelar Gomoku genom systemet |
| Drag | En spelare som placerar en sten på en ledig position i Gomoku på spelbrädet |
| Gomoku | Gomoku är ett brädspel där spelare turas om att placera stenar på ett rutnät. Målet med spelet för att vinna är att någon av spelarna ska få fem stenar i rad horisontellt, vertikalt ellerr diagonalt |
| Motståndare | Den andra deltagren i ett Gomoku spel, motståndaren kan vara en annan spelare men kan också vara dator |
| Spel/match | En omgång Gomoku mellan två motståndare som avslutas när en av spelarna vinner eller att spelet blir oavgjort |
| Spelbräde | Det är en rutnät där spelarna placerar sina stenar under spelet | 
| Position | En specifik plats på spelbrädet där en sten kan placeras. |
| Vinst | Ett resultat där en av spelarna har fått fem stenar i rad horisontellt, vertikalt eller diagonalt | 
| Sten | Det är en spelpjäs som placeras på spelbrädet av en spelare under en match | 
| Tur | Det är en period där en av spelarna får göra ett drag | 
| Vinst | Ett resultat där en spelare har fått fem stenar i rad horisontellt, vertikalt eller diagonalt.|
| Förlust | Ett resultat som visas när en motståndaren har vunnit matchen. |
| Oavgjort | Ett resultat i en match där ingen av sspelarna lyckades vinna spelet. | 
| Dator spelare | En programstyrd motståndare som spelar Gomoku mot en mänsklig spelare, lätt/medium eller svårt | 
| Svårighetsgrad | Det är den valda nivån på utmaningen när en spelare väljer att spela mot en dator | 
| Distansspel | Ett flerspelarspel där två spelare kör mot varandra från två olika platser | 
| Lokalt spel | Ett flerspelarspel där två spelare använder samma enhet och turas om att göra ett drag i Gomoku | 
| Spellänk | Det är en länk som gör det möjligt för en spelare att bjuda in någon annan till en specifik match | 
| Webbläsare | Programvara på datorn som används för att komma åt spelet för att köra, till exempel Google Chrome | 
| Enhet | Det är en fysisk enhet som används för att komma åt Gomoku, exempelvis mobiltelefon/dator | 
| Anonym spelande | En spelare som spelar Gomoku utan att skapa konto eller logga in | 
| Prestanda | Hur snabbt systemet reagerar på spelarna handlingar under en match, till exempel när en sten placeras på spelbrädet | 
| Tillförlitlighet | Systemets förmåga att fungera korrekt och bevara en pågående match mellan två spelare, till exempel vid tillfälligt anslutningsavgrott | 
| Icke-funktionella krav | Ett krav som beskriver kvalitet, egenskaper eller begränsning hos systemet istället för en specifik funktion | 
| Funktionellt krav | Ett krav som beskriver en funktion eller ett beteende som Gomoku ska utföra | 
| User story | En kort beskrivning på ett önskemål ur användarens perspektiv. Som användare, vill jag, för att. | 
| Krav | Ett villkor som är dokumenterat, något systemet måste uppfylla | 
| Spelinbjudan | Den information, vanligtvis en spellänk, som används för att låta en annan spelare ansluta till en match. |
