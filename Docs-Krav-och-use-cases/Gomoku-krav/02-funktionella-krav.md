# Funktionella Krav

## User Story

Som en spelare vill jag spela Gomoku mot en motståndare tills en av oss får fem i rad eller att spelet slutar i oavgjort.

## Spelet laddas

| ID       | Krav |
|----------|------|
| FR-01.1  | Ett tomt rutnät av förvald storlek 11x11, 13x13, 15x15, 17x17 eller 19x19 ska laddas. |
| FR-01.2  | Varje spelare ska tilldelas sina markeringar. |
